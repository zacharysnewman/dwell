Cost and gameplay. Options 0–5 keep leaves as blocks: each cell is still one 1 m leaf block for collision, breaking, placing, growth and the tree record. 1 is a vertex-normal change only (free in the mesher: one centre per tree, which the tree layer already knows). 2 adds a few triangles per exposed cell, derived from the neighbours like the octagon's joins (no new states). 3 adds alpha-cut quads (overdraw, a second draw pass); cards are a look and never collide.

Option 6 is a reference only: one special mesh per crown, not blocks. Breaking a leaf would have to remesh the crown, and it does not match the grid you collide with.

Content is prototype: the colours are the palette's leaf, bark and meadow ramps; the textures are painted here, not the game's.
